How to use this file

This is the only document allowed to go stale

Everything else in this folder is a rule — it is true until someone decides otherwise. This file is a reading — it was true at the timestamp in the header and is probably already wrong.

Regenerate it at the Friday close-out, every fortnight. Query the board, replace every number below, stamp the date. It should take ten minutes. If a figure here contradicts the live board, the board wins — always. Nothing in this file should ever be quoted without the date attached.
What belongs here, and nowhere else: row counts · status and WIP counts · which sprint is open · what is blocked and for how long · which cards are overdue · velocity to date · the current placeholder and open-question list. What does not belong here: any rule, definition, formula or policy. Those live in the six instruction documents and do not move. Limits are quoted below only as the yardstick a reading is measured against — the rule that sets them lives in Board Rules, and if the two ever differ, Board Rules is right.
