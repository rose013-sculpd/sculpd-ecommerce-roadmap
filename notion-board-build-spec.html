01 · Safety protocol

What I will not do

Read-only, everywhere except the new board

I will read the source database to copy titles, subtask hierarchy, status and any existing content. I will not edit, move, archive, re-parent, re-title or re-status a single row on it, and I will not touch any other database in the workspace.

New rows are created fresh in the new database, not moved. The originals stay exactly where they are, which is what makes the old board a real backup rather than a nominal one.

Reversible by design

Everything lands inside one new page. If it is wrong, deleting that page removes the entire experiment and changes nothing else.

I will report a before-and-after row count on the source database so we can both see it was untouched, and give you the new page URL as the last step rather than the first.
